### How to add the next case study

**Where it goes:**
In the `work/notebooks/` folder of my GitHub repo, next to the existing projects.

**The 3-Beat Shape (from Week 2):**
1. **Problem**: What real-world problem am I solving?
2. **What I did**: How did I apply ML to solve it?
3. **What came of it**: Results and recommendations.

**Steps to add a new case:**
1. Create a new `.ipynb` file in `work/notebooks/`
2. Write the 3 beats (Problem → Solution → Result)
3. Run the code and verify results
4. Update the main `README.md`
5. Commit + Push to GitHub

**AI transparency:**
Each new project is built with Claude AI assistance, with personal review of code and results before submission.
